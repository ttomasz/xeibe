Read GML in your browser

Open or drop a GML file or a saved WFS response (.gml, .xml file or an archive with them). Nothing is uploaded: xeibe, compiled to WebAssembly, reads it here, on your machine.

You see the layers, the schema xeibe infers and why, how it decided the axis order, the read report, and the data in a table and on a map.

The map converts coordinates with xeibe's own reprojection; datum shifts that need grids fetch them from cdn.proj.org. Basemap © OpenStreetMap contributors.

Select a feature on the map or a row in the Data tab to see its XML.
